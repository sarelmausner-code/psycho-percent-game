# פסיכו — אימון כמותי (עולם אחוזים)

משחק תרגול לחלק הכמותי בפסיכומטרי (עברית).  
**מדד אימון בלבד — לא ציון פסיכומטרי רשמי.**

## לשחק

אחרי דיפלוי, פתחו את קישור האתר במובייל או בדסקטופ.  
מומלץ לבטל השתקה (unmute) כדי לשמוע מוזיקה וצלילים.

## מה יש בדמו

- 8 שלבים בעולם אחוזים
- גנרטורים פרמטריים (תשובה מחושבת בקוד)
- טיימר, קומבו, מוזיקה אדפטיבית
- שמירת התקדמות מקומית בדפדפן (Dexie / IndexedDB)

## פיתוח מקומי

```bash
npm install

```

```bash

```
